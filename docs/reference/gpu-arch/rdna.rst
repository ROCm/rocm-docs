**************************************************
AMD RDNA architecture
**************************************************

The AMD RDNA™ architecture powers AMD Radeon™ and Ryzen™ GPUs. Detailed
microarchitecture documentation for RDNA is coming soon.

In the meantime, refer to the instruction set architecture (ISA) references
for each RDNA generation.
